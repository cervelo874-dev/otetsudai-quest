# 3頭身2Dアバター描画モジュール & AI位置合わせ・透過スタジオ

既存アプリ（Vite 5.4 + React 18.3 + TypeScript 5.5 + Tailwind 3.4 + Supabase）へそのままコピー＆ペーストで移植できる `src/features/avatar/` モジュールです。

## 主な特徴
- **全14レイヤー共通座標系（512×512px）**: 下から順に重なる14レイヤー（`background` 〜 `front_effect`）を定義。
- **全カテゴリ「なし（未装着）」選択可能**: 素体や目・口を含め、全14カテゴリすべてで制限なく「なし（外す）」を選択できます。
- **プリセットSVG非同梱**: 初期段階では不要なイラスト素材を含めず、AI生成等で作成したパーツだけをクリーンに管理できます。
- **ユーザー編集可能な目安ポイント（基準点）**: スタジオ上の頭・目・口・胸・腰・手・足元・ペット位置などの目安ポイントを、キャンバス上のドラッグまたは数値入力で自由に変更・追加・削除できます。
- **再クリック解除対応ツール**: スタジオの「消しゴム」「透過色スポイト」「目安ポイント移動」は、選択中にもう一度ボタンを押す（または `Esc` キーを押す）ことでいつでも解除して移動モードに戻せます。
