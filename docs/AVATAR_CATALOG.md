## 🛡️ 反映漏れ（未描画バグ）を100%防ぐための仕組み

### なぜ今回のバグが起きたか？
1. `AVATAR_OPTIONS`（選択肢の定義）に新しいアイテムを追加した際、描画関数（`renderBackground` や `renderAccessory` など）の `switch-case` に描画コードを追加し忘れていた。
2. TypeScriptの型チェックでは「switch-caseにそのIDが存在しない」ことが検出されず、デフォルト（`sky` や空文字）にスルーされてしまった。

### 今後の防御策（3層の安全システム）

1. **【自動整合性バリデーターの導入】 (`validateAvatarRegistry`)**:
   - アプリ起動時に、`AVATAR_OPTIONS` に存在するすべてのアイテムIDが、描画関数でサポートされているかを自動走査します。
   - もし描画処理が抜けているアイテムが存在した場合、コンソールに `🚨 [Avatar Warning] 未実装のアイテム描画があります` と明確に警告を出力します。

2. **【アイテム追加チェックリスト】（新規アイテム追加時）**:
   新アイテムを追加する際は必ず以下の3箇所を同時に更新します：
   1. `src/avatar.ts` の `AVATAR_OPTIONS` にアイテム定義を追加
   2. `src/avatar.ts` の該当描画関数（`renderOutfit`, `renderAccessory`, `renderBackground` 等）に `case '新ID':` を実装
   3. ショップ購入アイテムなら `src/presets.ts` の `shop`、ガチャ専用なら `src/actions.ts` の `rollPrize` に登録
